# 计算契约 moonmotor.step-response/1

## 输入与时间

输入为一份时间严格递增的单阶跃观察序列 `(t_i, y_i)`。时间列从明确选择的 `s / ms / us` 转换为秒，区间起点/终点和阶跃时刻都用秒表示。区间含两端样本。时间列在整个文件内必须完整、有限且严格递增；所选区间内的响应列也必须完整、有限。

阶跃时刻记为 `t0`，初始值 `y0`，目标值 `r`，幅值 `A = r - y0`。这三个参数由用户确认，不从波形中自动猜测。`A=0` 和非有限运算拒绝。

当 `t0` 不在样本时刻上时，以相邻样本线性插值补出边界样本。阶跃前样本不参与响应指标；全区间统计仍包含所选区间的全部样本。至少需要三个阶跃后样本。

## 超调与峰值

定义沿阶跃方向的归一化进度 `p_i = (y_i - y0) / A`。

`overshoot_percent = max(0, max(p_i) - 1) × 100`。

峰值取进度最大的样本，时间减去 `t0`；下降阶跃对应最小响应值。因此目标为零、负向阶跃也可以计算。峰值不插值，精度受采样限制。

## 10–90% 上升时间

在阶跃后的序列上，分别寻找从低于 0.1/0.9 到达到或高于该阈值的第一次穿越，在线段上插值出时刻 `t10` 和 `t90`；结果为 `t90 - t10`。

如果观察起点已达到某阈值，不能知道它何时首次穿越，返回不可用；缺少任一穿越也不可用。对下降阶跃使用同一归一化定义。

## 调节时间

误差带半宽 `b = abs(A) × band_percent / 100`，`band_percent` 必须大于 0 且不超过 50。

在阶跃后序列中找最后一个满足 `abs(y_i-r)>b` 的样本。其后第一个样本为观察到的进入时刻，减去 `t0` 得调节时间。至少要求进入样本及其后还有一个样本，即至少两个末尾带内样本。全部样本带内则返回 0；最后或倒数第二个样本仍带外时不可用。

不在线性插值中推测带边穿越，因此这个估计保守到采样时刻。`observed_in_window` 只描述所选窗口，不能证明此后不再出带，也不是控制理论中的稳定性证明。

## 末段均值与误差

阶跃后观察时长 `D = t_last - t0`。末段起点 `t_tail = t_last - D × tail_percent/100`。使用所有 `t_i >= t_tail` 样本的算术平均，不做时间加权。`tail_percent` 必须大于 0 且不超过 50。少于三个样本时警告。

末段误差 `r - mean_tail`，保留符号。百分比除以 `abs(A)`。界面使用“末段误差”，避免把有限窗口估计当作已经证明的最终稳态。

## 绝对误差积分

对分段线性误差 `e(t)=r-y(t)` 的绝对值积分。相邻端点误差同号时为梯形面积；异号时在零点处分为两个三角形。不是直接对 `abs(e_i)` 作梯形积分，因为后者在跨零线段上会高估面积。

## 统计

- 均值和总体方差使用 Welford 单次扫描。
- 总体标准差分母为 `N`，不是样本标准差 `N-1`。
- RMS 使用缩放平方和，避免直接对大数平方。
- 若任意最终指标为非有限值，返回失败，不输出 `NaN`、无穷大或伪造的零。

## 绘图与导出

曲线超过 1800 点时按时间顺序分桶，保留每桶最小/最大响应及两端点，保持尖峰。悬停显示的是绘图点，不声称原始点插值查询。比较曲线以各自阶跃时刻对齐。所有指标仍以全部原始分析样本计算。
