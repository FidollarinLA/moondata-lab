# 范围纠正 — 2026-10-18

用户明确纠正：需要覆盖不同领域的数据应用，不应限定为 Motor / 电机。此前将专业背景当作产品范围，是实现方的误解。

## 已明确的方向

- 产品名改为 MoonData Lab，通用版本目录为 moondata-lab。
- 上传、结构识别、统计、图表、报告与模型工具调用面向多领域表格数据。
- 销售台账、库存、问卷、传感器与实验记录可以作为不同示例，不将任何一种领域写死到默认流程中。
- 电机阶跃分析最多保留为可选专业模块，不能成为导入和一般分析的前置条件。
- 数据生成的输出必须明确标注为合成数据，区别于实测或业务事实。

## 正在澄清的术语

“数据生成”可能指从自然语言生成新的表格/模拟数据/训练数据，也可能指上传已有数据后生成分析、图表和报告。已向用户提出此区别，避免再次将生成和分析混为一谈。

在答复前，先完成两种方向共同需要的品牌、目录、领域解耦和计划调整；不把旧的电机验收记录作为新通用版的完成证据。

## 历史与当前状态

- 原版目录 moonmotor-lab 保留，尚未推送 GitHub；通用版保留相同的初始 Git 历史。
- 原始计划归档在 docs/archive/MOTOR_V0_PLAN.md。
- 旧截图与旧验收记录属于电机专用原型，不能代表通用功能已经完成。
- 发布前必须重新验证通用数据路径，并生成新的截图与验收记录。
