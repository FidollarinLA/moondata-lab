# 本地小模型与自由画图

## 使用

在当前工作区执行 `./moondata-lab/start.ps1`。如果已经准备好本地模型，该入口同时启动模型与工作台。访问 http://127.0.0.1:4321 。停止启动终端会清理本次创建的模型进程。

其他电脑从源码开始：Windows x64、Node与MoonBit准备好后，在项目目录运行：

```powershell
node scripts/setup-local-model.mjs
node scripts/start-with-model.mjs
```

权重与运行器只写入忽略的 .local/model，不安装全局程序、不写注册表、不向 Git 提交模型。权重约639MB、运行器压缩包约20MB；启动使用6个CPU线程和8192上下文，无需CUDA依赖。与应用一起运行时会占用额外内存，启动和推理速度取决于机器。

默认应用端口4321，模型4324。可以通过 PORT、LAB_LOCAL_MODEL_PORT改变；只监听127.0.0.1。端口已占用会报错，不终止其他程序。应用只清理自己创建的模型子进程。

只运行 `node server/index.mjs` 仍是无模型模式，除非显式设置模型环境。远程模型仍可按 README 使用；本地启动入口优先加载本地模型。

## 操作顺序

1. 选“其他 / 自定义”生成数据，或上传支持的表格文件。模板不是领域限制。
2. 在自由画图区选择X、勾选一个或多个Y、选择自动/折线/散点/柱状。点“按我的选择画图”。
3. 要用对话，可点“让助手使用当前选择”，再说“把我当前选择的几列换成折线图”。也可直接指定“以收入为横轴，支出为纵轴画散点图”。
4. 模型输出受约束的配置；字段和类型校验后才调用计算工具。画出后配置回填表单，可继续点击修改。
5. 下载SVG、Markdown或JSON，核对原始来源、排除行数、聚合方式和计算值。

“一键推荐”是按字段类型的确定性操作；本地模型负责自由描述的图表规划。明确的模板、概览和当前分析命令直接走工具，会说明无需模型规划。

## 模型与来源

使用 [Qwen 官方 Qwen3-0.6B-GGUF](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF) 的 Q8_0 权重（Apache-2.0），不是本项目训练的模型。官网下载在本机网络不可达，实际下载自 [Qwen 官方 ModelScope 仓库](https://modelscope.cn/models/Qwen/Qwen3-0.6B-GGUF)，同时核对公开的同文件LFS SHA-256。

- 权重：Qwen3-0.6B-Q8_0.gguf，639446688字节。
- SHA-256：9465e63a22add5354d9bb4b99e90117043c7124007664907259bd16d043bb031。
- ModelScope revision：6abe20cd0aed577f4d0b267935868ecae190aee9。
- 运行器：[llama.cpp b11718 Windows CPU x64](https://github.com/ggml-org/llama.cpp/releases/tag/b11718)，其源码遵循MIT许可。
- ZIP SHA-256：92cc529b29a43f9a30e21d490cb2e95062acd0b59af6fee8b3b52b28074f838c。

setup脚本固定版本、核对长度和摘要后才激活文件。再次执行会复用已校验的下载。源码交付包不包含第三方权重和二进制；本机下载是独立依赖缓存。

## 能力与边界

小模型只输出受JSON Schema约束的绘图配置：action、X、Y列表、图类型、聚合方式与方案说明。不执行代码，不计算报告数值，不把模型意见当作因果结论。底层生成、聚合、统计和相关计算仍由MoonBit承担。

传给本地模型的是问题、字段名称/类型和当前选择，没有原始数据行或绘图采样点。它不访问远程推理服务；初次下载运行文件需要网络。

一次最多考虑16个候选字段，优先提问中出现的字段与当前选择；宽表可先在界面选中目标字段再提问。界面仍能选择所有列。长字段名、模糊表达和复杂意图可能导致错误或达到上下文限制，明确的手动选择始终可用。

只换图表类型时程序保留用户已有坐标与汇总配置；明确指定不存在的横轴会先拒绝，不悄悄用另一列替代。不能据此保证任何自然语言都被正确理解；请核对回填坐标与报告。

当前模型专注已读入数据的图表规划；生成新数据仍用模板/自定义方案，或可选远程模型的方案工具。不提供任意文件读取、PDF/图像识别、训练、预测、筛选表达式或自动数据清洗。

## 实测

`node scripts/test-local-model.mjs` 执行真实CPU模型推理和真实浏览器对话，不用模拟模型回复。覆盖明确坐标、多纵轴、风格变更、类别求和、数值散点、纯文本计数、缺失字段拦截，以及图表/报告一致。记录在 artifacts/local-model-acceptance.json。此小组合成验收不能代表开放领域语言理解准确率。
