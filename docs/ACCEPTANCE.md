## 验证环境

- Windows x64，Node.js 24.19.0。
- moon 0.1.20261012，moonc v0.10.15+943464bfa。
- Playwright 1.62.1，Microsoft Edge 155.0.4283.45，无头模式。
- 桌面视口 1440×1050，移动视口 390×844。
- 未据此宣称 Linux/macOS、Firefox/Safari 或 Native 后端已验证。

## 数学核对

1. 简单斜坡的上升时间 1.6 s、IAE 10、调节时间 2 s 与独立手算一致。
2. 下降到零的阶跃按方向计算超调，不以目标值为分母。
3. 跨零误差线段的绝对积分按两段三角形面积计算。
4. 非采样时刻的阶跃边界线性插值，起始已跨过阈值时不编造上升时间。
5. 只有一个末尾带内样本时不声称调节完成。
6. 二阶合成数据的峰值超调与闭式公式核对，容差考虑采样分辨率。

## 本机一次性能测量

10 万行、2 列、1299449 字节的确定性合成数据：导入约 297 ms，分析约 90 ms，显示曲线 977 点，指标使用全部 100000 个原始样本。结果由 scripts/benchmark.mjs 记录到忽略的 artifacts/benchmark.json。

这是一次本机运行，不是最坏情况、峰值内存或其他平台吞吐保证。超宽表格、超长文本和并发会话可能有不同资源表现。

## 已知限制与下一步

- 内置模式是有限规则识别，不是大模型；开放自然语言需要配置模型。
- 原始数据不发送给模型，但文件名、列名和统计结果会在模型模式提问时发送。
- 当前数据不持久化；刷新后参数需重新确认，重启后数据清空。
- 多阶跃必须先选区间；没有自动阶跃检测、频率分析、参数辨识、模型训练或实时 CAN。
- 实验比较显示目标、初始值、误差带、末段窗口和观察时长差异，不自动做因果或显著性推断。
- 外部模型实测、真实用户数据回归和 GitHub 远端 CI 仍需后续完成。

## 推送方法

用户已经授权推送。只缺本机 GitHub 认证或一个连接器可写的目标仓库，无需重复请求项目发布许可。完成认证后：

```sh
node scripts/publish-github.mjs
```

默认创建当前账号下的私有 `FidollarinLA/moonmotor-lab` 仓库，推送 `codex/initial-workbench` 并核对远端 SHA。已有其他仓库可显式传 `owner/repository`。脚本不强推、不覆盖其他分支、不改全局 Git 配置。成功后应更新本记录的推送与 CI 状态。
