# 实施与迭代记录

## 2026-10-18：建立项目

在独立 moondata-lab 目录建立计划、开发约定、许可证和 Git 历史。使用当前工作区已存在的 MoonBit 0.10.15 工具链进行构建，没有改动其他项目。

## 迭代一：数值链路

实现 CSV、统计、单阶跃响应和 JSON 导出。首轮测试发现按 UTF-16 单码元切片丢失表情字符，改为字符迭代并增加 Unicode/BOM/多行覆盖。

JS 边界验证又发现 MoonBit Option 的默认 JSON 编码是数组形式。为可用/不可用指标明确实现 number/null 边界，避免界面将数组误当数字。

## 迭代二：完整产品

实现本机 HTTP 会话、中文工作台、文件上传、列映射、双实验、响应图、结果表和四种导出。加入合成响应公式和来源标注。核心计算始终来自 MoonBit。

## 迭代三：Agent

实现真实工具调用协议、有限内置模式、参数限制、调用记录、凭据隔离、模型超时/轮数/体积限制、取消与恢复。用本地 HTTP 模型协议桩进行浏览器实测，不将桩响应当作外部模型效果。

补充检查发现仅调用元数据查看工具也可能被误标为完成计算，调整为只有响应指标工具真正执行后才能标注计算完成；对未计算的模型回答显示限制。模型响应流错误也统一转换为不含密钥的提示。

## 迭代四：浏览器验收修复

- 修复在双实验模式中只分析当前实验后，导出报告却包含两份实验的问题；报告改为严格跟随可见结果。
- 手机曲线改用响应式 SVG 坐标，避免固定 1000px 图表缩到手机后标签无法阅读。
- 切换物理响应列时清空初始值、目标值和单位，防止把转速参数带到电流分析。
- 参数变化后清空旧结果与下载状态；明确提示先前对话属于旧条件。
- 比较时提示误差带、末段窗口和观察时长差异。
- 文本显示文件名/模型回复，报告转义不可信名称；浏览器校验包含特殊字符的文件名和完整内容指纹。

## v0.2：按用户确认扩展为生成与分析双流程

用户明确“两者都做”。在 moondata-lab 通用目录实现 generator / explore MoonBit 核心、8类字段、四领域模板、JSON/JSONL导入、五种分析方式与三种数据下载。默认页面不再依赖电机或时间序列；原专业模块仅保留回归。

生成方案由模型提出时先显示字段编辑器，不自动创建数据。助手工具绑定当前数据集；不提供执行代码工具。离线仅识别明确命令，不伪装自由自然语言。

本轮迭代修复：生成浮点取样多消耗随机数；日期末端和序列范围校验；JSON下载被重复字符串编码；模型精简结果意外含绘图行与任意导入provenance；字段方案变更后旧助手结果覆盖编辑。新增独立数学与跨格式重导入测试。

浏览器验收覆盖两条流程、可复现性、格式、图表、报告、旧查询失效、390px、恶意文本和模型取消。修正测试等待新文件加载的时机，避免把上一份数据的已完成状态误认为新文件完成。

新验收、截图、方法与接口已独立记录；旧电机方法与验收归档。发布描述和默认仓库均改为 MoonData Lab。GitHub 仍缺 CLI 登录，目标仓库连接器查询返回不可访问；没有因此跳过本地开发，也没有宣称已推送。

交付检查发现 Git 默认换行规范化会改变合成 CSV 文件的字节指纹；为这些示例保留原始字节，并增加 CSV 与 JSON provenance 指纹一致性验证，避免跨平台检出后示例来源不一致。

## v0.3：其他/自定义、自由坐标与本地小模型

根据用户截图和新要求新增自定义入口、独立的X/多Y绘图区、三种图型与确定性推荐。新绘图区使用实际数值和日期间隔，各序列分别排除缺失；更多统计折叠保留。图表配置可回填，点击和对话都能修改。

在项目.local内下载并校验Qwen官方0.6B Q8权重和llama.cpp CPU便携运行器。Hugging Face域名在本机网络不可达，使用Qwen官方ModelScope仓库并比对同文件SHA-256。首次解压时Windows PowerShell的Archive模块不可用，改用系统tar；未改动系统安装。

首轮真实推理发现模型倾向无谓澄清、继承多余字段或改变汇总方式。通过少量字段配置示例改善规划，并把仅换图型定义为配置补丁，程序保留用户未要求改变的X/Y/汇总。明确不存在的横轴由字段校验阻止，错误会展示，不生成替代图。模型输出必须通过字段/类型/规模校验，不能运行代码。

实际CPU推理与真实浏览器对话已经跑通；没有用模拟输出代替本地模型测试。新增Node多曲线、配对、日期、聚合、纯文本计数、协议与边界测试；新增浏览器自由选择及真模型路径。模型仍受8192上下文与16候选字段约束，不承诺任意格式或任意问题。
